# Architecture

This document is a placeholder for the Room State Manager design notes.

Current Hubitat code layout:

- `apps/SimpleHome.groovy` - parent app.
- `apps/SimpleRoomState.groovy` - room state child app.
- `apps/SimpleRoomLighting.groovy` - room lighting child app.
- `apps/SimpleModeManager.groovy` - mode manager child app.
- `apps/SimpleHouseIntentLighting.groovy` - house intent lighting child app.
- `apps/SimpleCircadianLighting.groovy` - circadian lighting child app.
- `drivers/SimpleRoomMetaDevice.groovy` - room meta device driver.
